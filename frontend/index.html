NAVIGATION PIPELINE

From observation to georeferenced action.

Each observation is associated with rover state and position before being made available to the treatment and mission control layers.

01 OBSERVE Acquire field image

05 DATA & METHODOLOGY

DATA PIPELINE

Measurements remain traceable to their field context.

The backend records telemetry, location, detections and treatment events as timestamped observations. This allows individual events to be reviewed against rover position and environmental state.

Detection confidence is retained with the original observation. Treatment records are maintained separately so that an inferred target and the resulting intervention can be evaluated independently.

INPUT Sensor stream Telemetry / GNSS / imagery
→
PROCESS Inference Detection / localization
→
RECORD Event database Timestamped observations
→
OUTPUT Field action Treatment / mission state
NOTE 01 CURRENT LIMITATIONS
  • GNSS accuracy is dependent on satellite visibility and local environmental conditions.
  • Visual detection performance depends on image quality, illumination and training data coverage.
  • Treatment decisions require validation before deployment in operational field conditions.
  • Current platform communication is being developed independently of the final embedded hardware interface.
